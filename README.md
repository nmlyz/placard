Placard writes a one-line museum label for an ordinary office object,
catalogued as if it were an ancient artifact dug from a lost
civilisation: a catalogue date, a material, an inscription, and a donor,
in the dry voice of a curator who has read ten thousand labels and
laughed at six.

## Run it

```sh
python3 main.py
```

It writes the placard to `/output/entry.txt` (`OUTPUT_DIR` overrides
the directory). No network access needed; the same text, byte for byte,
on every run.
